# Реестр граждан — Admin Dashboard

Тестовое задание: административная панель для учёта граждан с картотекой, детальными карточками и аналитикой.

## Архитектура

Проект построен по методологии **Feature-Sliced Design (FSD)**:

- `app/` — инициализация приложения, layouts, роутинг
- `pages/` — страницы (Dashboard, Картотека, Детали гражданина)
- `features/` — функциональные блоки (табы карточки гражданина)
- `entities/` — бизнес-сущности (модель Citizen, колонки таблицы, UI-компоненты)
- `shared/` — переиспользуемые утилиты, моки, константы, UI-кит


## Стек

**Frontend:** React 19, TypeScript, Vite, React Router

**UI:** Tailwind CSS v4, shadcn/ui, Base UI

**Данные:** TanStack Table, Recharts 

**Моки:** @faker-js/faker

**Прочее:** dayjs

## Функционал

- **Dashboard** — статистика по гражданам (карточки со статистикой, динамика регистраций за период, распределение по статусам)
- **Картотека граждан** — таблица с поиском, сортировкой, пагинацией
- **Карточка гражданина** — 4 раздела:
  - Личные данные (редактируемая форма, сохранение в localStorage)
  - Семья, Образование, Работа — связанные сущности (read-only)

## Запуск

\`\`\`bash
npm install
npm run dev
\`\`\`
